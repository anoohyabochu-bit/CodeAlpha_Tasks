CodeAlpha AI Internship - Task Repository

This repository contains the AI projects completed as part of my internship. Each task focuses on applying Artificial Intelligence and Python concepts to solve practical problems.

📌 Task 1 – Language Translation Tool

A Python-based GUI application that translates text from one language to another using a translation API.

Features:

- User-friendly GUI
- Source and target language selection
- Text translation
- Clear translated output
- Supports multiple languages

Technologies: Python, Tkinter, Translation API

---

📌 Task 2 – FAQ Chatbot

An NLP-based chatbot that answers frequently asked questions by finding the most similar question from a predefined FAQ dataset.

Features:

- FAQ-based question answering
- Text preprocessing
- Similarity matching
- Simple and interactive interface

Technologies: Python, NLTK, NLP, Cosine Similarity

---

📌 Task 3 – AI Music Generation

An AI-based music generation project that uses an LSTM neural network to learn patterns from MIDI music and generate new musical sequences.

Features:

- MIDI data processing
- LSTM-based neural network
- Music pattern learning
- Automatic music generation

Technologies: Python, TensorFlow/Keras, NumPy, Music21
